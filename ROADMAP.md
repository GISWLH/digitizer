# Roadmap

Progress is measured by reproducible results, not feature counts.

- [x] THU-based extraction with source-bound, reviewed legend exclusions.
- [x] Public CSV, masks, overlays, reconstructions and machine-readable scores.
- [x] Real FLUX paper panels, including unsuccessful and unscored cases.
- [x] Complete Chinese, English and Japanese READMEs; editable Excalidraw identity.
- [ ] Improve dense daily series: model stroke geometry near sharp turns and
      quantify visible-vs-occluded support without filling hidden spans.
- [ ] Add independently archived author time series with redistribution rights.
      Freeze a held-out FLUX set before tuning; report per-case and per-series
      coverage, precision and uncertainty calibration.
- [ ] Add real latent/sensible heat, ET, CH4 and N2O figures with verified units
      and instrument/processing provenance. Current FLUX examples cover carbon.
- [ ] Provide an interactive calibration editor with source-bound review history.
- [ ] Add station-long-table export with explicit baseline checks and source
      semantics; never infer missing coordinates or register duplicate stations.

These unchecked items are planned, not currently supported features. Contributions
should improve a concrete failure or add independent evidence.
